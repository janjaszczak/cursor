AGENTIC LOOP (Observe → Act → Verify → Decide → Repeat)
Applies when implementing or fixing.

AGENTS resolution (every workspace):
1. If `<repo-root>/AGENTS.md` exists → read it for verify commands and repo DoD.
2. Else read `~/.cursor/AGENTS.default.md` (Windows: `%USERPROFILE%\.cursor\AGENTS.default.md`).
3. Offer `python ~/.cursor/scripts/bootstrap-agents-md.py` if user wants a persistent per-repo AGENTS.md.

Definition of Done — ALL must be true:
1. Acceptance criteria from plan/task or resolved AGENTS met (cite which).
2. Verification command exits 0 (name exact command).
3. No new linter/type errors in touched files.
4. Shrimp verify_task ≥80 OR verifier pass OR explicit user sign-off.
5. No orphan agent scratch (skill keep-tidy).
Even C0 fixes: one-line verify (lint or targeted test) before marking done.

Verify-first: before first edit, state verify command(s) from resolved AGENTS (repo or AGENTS.default.md) or scripts/quality-gate.py. After changes: run verify; max 5 iterations then STOP + blocker.

Checkpoint narration: multi-step/long-running work → 1–2 line "what changed / what's next" at natural breakpoints (after each Shrimp task or tool-call batch), not only at the end; length still bound by "Concise by default".

Revert over iterate: if diverging from approved plan → revert, refine plan, re-run — not many follow-up patches.

Stop conditions: 3 identical verify failures or no diff after 2 attempts → STOP; destructive ops need rollback + user confirmation; Shrimp continuous stops on verify <80 or ambiguity.

Model selection: plan/architecture/security review → thinking; implement/fix/test → fast.

COVE (Chain of Verification — analysis/planning only, not trivial Q&A)
Internal procedure (do not expose steps): Draft → 3–5 verify questions → answer from evidence → revise.
Complexity: C0|C1|C2|C3. Impact: I0|I1|I2|I3. Max iterations: C0∧I0=1 | C1∨I1=2 | C2∨I2=3 | C3∨I3=4 | C3∧I3=5.
Footer: C1+/I1+ → "CoVe: zastosowano (N pytań weryfikacyjnych)."; C0 I0 → "CoVe pominięte (C0 I0)."
